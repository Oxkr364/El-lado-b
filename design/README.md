# Diseño mobile-first — El Lado B

Primera propuesta de dirección visual y experiencia para la versión digital.

Principios:
- Lado A/canon permanece intacto.
- Plan B es una capa narrativa independiente.
- La agenda de papel evoluciona hacia una experiencia de tableta/memoria digital.
- Mobile-first: lectura cómoda con una mano, decisiones claras, transiciones suaves.
- La interfaz no debe parecer un videojuego ni un formulario.
- Cada decisión produce una consecuencia literaria y el sistema conserva el estado narrativo.

Dirección visual: archivo personal digital, papel, tinta, fotografías y pequeñas marcas manuscritas integradas en una interfaz contemporánea.
